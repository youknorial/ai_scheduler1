# AI Scheduler
AI Scheduler は、ユーザーの生活リズム・固定予定・長期目標をもとに、AI が日々のスケジュールを提案するアプリです。

## 目的

目標を立てても日々の行動に落とし込めない人に対して、今日やるべきことを分かりやすく提示し、予定変更や未達成があった場合もスケジュールを調整できるようにします。

## 主な機能

- 生活リズムの登録
- 固定予定の登録
- 長期目標の登録
- 今日のスケジュール表示
- タスクの達成・未達成記録
- 日次振り返り
- AI によるスケジュール提案
- AI 相談
- 進捗確認

## 画面構成

- ホーム
- カレンダー
- 目標
- 進捗
- AI 相談

## 最初に作る範囲

最初は完璧な AI 機能までは作らず、以下を優先して作ります。

1. 初回入力画面
2. ホーム画面
3. 目標登録画面
4. 今日のスケジュール表示
5. 進捗・振り返り画面
6. AI 相談画面の見た目

## 今回は作らないもの

- 画像や PDF からの予定読み取り
- LINE メッセージ解析
- 完全自動の再スケジュール
- 高度な AI 分析
- 通知機能
