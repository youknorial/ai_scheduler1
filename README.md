# AI Schedule Secretary App

AIが秘書のように、長期目標・日々の予定・進捗・疲労感をもとに、現実的なスケジュール提案と再調整を行うアプリです。

## MVPの目的

3ヶ月以内に、自分が1週間使えるAIスケジュール管理アプリのMVPを作ることを目標にします。

## 技術スタック

- Expo
- React Native
- TypeScript
- Supabase
- OpenAI API
- Zod
- Zustand

## 開発方針

- 最初はAIなしで予定管理の土台を作る
- 次に簡易スケジュール生成を実装する
- その後、AI秘書モードを追加する
- AIの提案は自動反映せず、ユーザー承認後に反映する
